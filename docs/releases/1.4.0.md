Stewart 1.4 is about the first hour with a new project: fewer steps to your first automation, and clear answers when
something is not set up yet.

## Highlights

**`make doctor` checks the whole path.** Besides the container, it now connects to Home Assistant and tells you
whether the token belongs to an administrator, whether Home Assistant has a location for sun schedules, whether the
Stewart integration is installed, and whether the store answers. Every line says what to fix.

```
  connection   ✓  Home Assistant 2026.9.4 at ws://homeassistant.local:8123/api/websocket
  token        ✓  belongs to Stewart, an administrator
  location     ! warn  Home Assistant has none, so sun schedules fail; set it under Settings → System → General
  integration  ! warn  not installed; apps need it only to expose entities
  store        ✓  answers at redis://valkey:6379/0
```

**A friendlier first app.** New projects start with a short `HelloApp` that greets you in the log and with a
notification in Home Assistant. The bigger exposure demo lives on as `ChangeCounter`, switched off until you install
the integration.

**`make app NAME=PorchLight`** creates an app and its test, ready for `make test`.

**`stewart check` shows where every app runs**: a table of your apps with their class, the worker each one runs on,
and whether it is enabled, paused or disabled.

**Valkey only when you need it.** The store now runs under a Compose profile. If no app keeps data across restarts,
remove two lines from `.env` and Valkey stays off.

## Also new

- `make check`, `make app-pause APP=…`, `make app-resume APP=…`, `make app-reset APP=…` and
  `make worker-restart WORKER=…` in new projects.
- The Helm chart creates a Service for the admin API once it listens beyond loopback.
- The README starts with a Docker-only install, and the install guide covers Windows through WSL2.

## Upgrading

Run `make upgrade VERSION=1.4`. Existing projects keep working unchanged; the new Makefile targets and the optional
Valkey profile come from the skeleton when you want them. The
[upgrading guide](https://stewart-php.github.io/docs/help/upgrading/) lists the lines to copy.
