Stewart 1.6 lets you change apps and their settings without restarting: a reload restarts the apps on the current
code while the connection to Home Assistant stays open, and `make watch` reloads every time you save.

## Highlights

**`make reload` applies your changes in place.** It checks the project as `make check` does, then restarts every
worker on the code as it is now. Edited apps, `services.php` and regenerated classes take effect, and Stewart neither
reconnects to Home Assistant nor fetches every state again. If the check fails, nothing changes, and `make status`
shows why on its new `reload` row:

```
reload         failed 12s ago: App "battery-alert" sets option "treshold", which matches no parameter of App\BatteryAlert::__construct(). Did you mean "threshold"?
```

`docker compose kill -s HUP stewart` and `POST /api/reload` on the admin API do the same.

**Settings and new apps too.** A reload rereads `stewart.yaml` and the `apps/` directory: added and removed apps,
their options, `enabled`, `paused`, `worker`, and `workers` all apply. A change to any other setting, such as
`persistence` or `mqtt`, waits for a restart, and the `reload` row says `partly applied` and names it.

**`make watch` for development.** It runs Stewart in the foreground like `make run`, accepts the same `ONLY` and
`DRY_RUN`, and reloads a second or two after you save a file in `apps/`, `services.php` or `stewart.yaml`. A save that
breaks something keeps the apps running as they were and logs the error.

## Also new

- A reload does not count toward a worker's restarts, and it brings a quarantined worker back.
- After a reload removes an app, its exposed entities are deleted after the usual grace when `expose.prune` is on.
- `stewart_reloads_total{outcome}` counts reloads.

## Upgrading

Run `make upgrade VERSION=1.6`, then restart Stewart. `make status` and the other control targets need the daemon
on 1.6 too. To get `make reload` and `make watch`, copy them from the skeleton's Makefile. A `SIGHUP` now reloads
Stewart instead of stopping it, also in Git mode. The
[upgrading guide](https://stewart-php.github.io/docs/help/upgrading/) has the details.
