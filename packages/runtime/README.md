# stewart-php/runtime

Stewart broker, workers and the channel protocol between them.

```bash
composer require stewart-php/runtime
```

Part of [Stewart](https://github.com/stewart-php/stewart-php): Home Assistant automations in PHP. Start a project from
[stewart-php/skeleton](https://github.com/stewart-php/skeleton) rather than requiring packages one by one.

This repository is a read-only split of the monorepo. Open issues and pull requests at
[stewart-php/stewart-php](https://github.com/stewart-php/stewart-php).
